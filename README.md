### Introduction
Welcome to *Mixterial*, the repository that contains all universal code, pages, assets and information that we use across everything web related. This includes, but is not limited to:

- Web-pages
- Websites
- Web applications
- WebView applications
- Web games
- Browser extensions

Our goal is to eventually create an 'all in one' framework for web developers. While everything within this repository is what we use personally, we aim to create an entire system for everyone. Instead of starting development from the ground up, it's always nice to have something to build upon.

---

### Contents
To summarise everything and keep things short, we have listed the main contents of this repository. Directories and folders containing too many files will not have their contents listed.

- Core CSS ```All web related elements with several variations for each, animations, UX, etc```
- CSS themes ```33 themes (including all Catppuccin themes) with individual styles, liquid glass, blurred and semi-transparent designs```
- Core JS ```Everything that the core CSS and CSS themes require as well as management for themes, languages, cookies and data collection```
- Documentation ```Documentation covering our terms of service, privacy policy, payments & refunds as well as legal notices```
